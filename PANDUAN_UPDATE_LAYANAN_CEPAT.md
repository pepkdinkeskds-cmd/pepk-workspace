# Panduan Update Layanan Cepat

Paket ini memperbarui Layanan Cepat pada Beranda PEPK Workspace menjadi satu pintu **Pengajuan PEPK**.

## Cara memasang

1. Ekstrak ZIP.
2. Unggah seluruh isi folder `pepk-workspace-main` ke repositori GitHub Pages yang aktif dengan mengganti file lama.
3. Jangan menghapus file lain di repositori.
4. Tunggu GitHub Pages selesai memperbarui situs.
5. Buka Beranda dengan hard refresh (`Ctrl+F5`).

## Uji produksi

1. Pastikan Layanan Cepat hanya berisi satu kartu **Pengajuan PEPK**.
2. Pastikan tombol bertuliskan **Mulai Pengajuan**.
3. Klik tombol dan pastikan Submission Portal terbuka.
4. Pastikan portal menawarkan Dokumen, Agenda, dan Materi Monev.
5. Pastikan tidak ada tombol Google Form pada Layanan Cepat.
6. Pastikan keterangan status melalui tautan unik email tampil.

Perubahan masa aktif dan Riwayat Agenda belum termasuk dalam paket ini.
