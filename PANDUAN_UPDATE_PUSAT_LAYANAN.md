# Pembaruan Pusat Layanan — SERVICE_HUB_02

## Perubahan

- Layanan Cepat di Beranda dibuat ringkas mengikuti tinggi konten.
- Pusat Layanan menggunakan satu pintu `Mulai Pengajuan PEPK`.
- Dokumen, Agenda, dan Materi Monev dibuka melalui Submission Portal yang sama.
- Panel kedua menjelaskan status dan perbaikan melalui tautan unik di email.
- Tautan Google Form lama tidak digunakan pada Pusat Layanan.
- Tautan Operator Console tidak ditampilkan pada website publik.

## Cara memperbarui

1. Unggah seluruh isi paket ke repository GitHub Pages dan timpa file dengan nama yang sama.
2. Tunggu deployment GitHub Pages selesai.
3. Buka Beranda dan Pusat Layanan dengan `Ctrl+F5`.
4. Pastikan tombol `Mulai Pengajuan` membuka Submission Portal.
5. Periksa tampilan Beranda dan Pusat Layanan pada desktop serta ponsel.

## Batas perubahan

Paket ini tidak mengubah backend, database, Operator Console, Submission Portal,
masa aktif Agenda, maupun Riwayat Agenda.
